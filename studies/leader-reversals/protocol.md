# 训练中领先答案反转：事后轨迹分析方案

问题：训练早期领先的答案，后来是否被其他答案反超？反转发生在哪些已保存的评估步？

这是在原实验结果已经存在、部分终点结果已知之后制定的探索性分析，不是新的预注册或独立确认实验。分析不重训、不修改原始数据，也不更新公开论文。

## 范围与单位

- 主要分析：rfm-mechanism/results/all_runs.csv 中全部80条 confirmation 轨迹，p17为50个方向，p23为30个方向。必须与 frozen/confirmation_plan.json 完全对应。
- 补充分析：同一清单中的所有其他轨迹，按 phase、p 和初始化/干预类型分组。共844条；其中50条 probe 只有6次评估，其余794条有60次评估。短轨迹的稳定仅指截至第5步，不能冒充截至第59步的稳定。
- 第0步是初始度量下的首次核拟合；第t步已经完成t次AGOP度量更新。原完整轨迹观察窗口止于59，不能据此断言之后永不反转。
- 每个初始化方向是一项描述性观察。同轨迹的p个测试点、同种子的配对干预、确定性基底和重复运行不能作为额外独立样本。不做总体概率或显著性推断。
- 同时报告逐测试点答案，以及把正确类别移到偏移0后跨测试点平均的得分剖面。后者不是逐点准确率。

## 数值口径

对每个时刻、每个得分向量s，令RMS为减去类别均值后的均方根。

tol = max(rtol * RMS, 64 * float64_epsilon * max(abs(s)))。

默认 rtol=1e-8，主要80方向另检查1e-10、1e-6、1e-4（最后一项为更保守压力口径）。这只是并列敏感性口径，不是对整个训练数值误差的严格上界。

领先集合 W(t) = {c: max(s(t))-s(t,c) <= tol(t)}。全部类别都在集合内时，称尚无可区分的领先答案。保留原始argmax跳动供对照，不将近并列中的下标改变直接算作可靠反超。

## 主要终点：早期领先集合是否后来整体落后

锚点 k = 0,1,2,3,5,10,15,20,30,40,50,55,59，限实际可观察步。

固定锚点集合W(k)，扫描所有后续t。若集合外最高分减集合内最高分 > tol(t)，则记录早期领先集合被整体反超；记录首次发生步、终点是否仍落后，以及锚点是否只有一个明确领先答案。集合内的并列成员彼此换位不算反超。

尚无可区分领先集合的锚点单独列出，不当成“领先后一直稳定”。每条轨迹同时给出被反超测试点数和“至少一个测试点反超”指示；主要汇总分模数报告，不用较多测试点的模数隐式加权。

## 反转时间和正确性

- 正确性反转：正确答案分数减最高错误答案分数，按tol判为正/负/不确定。跳过不确定步，比较连续两个明确状态；记录正转负、负转正，以及上一次明确状态的步和新状态首次出现的步。出现并列时，实际交叉时间只能定位在这一区间。
- 领先集合事件：从第一个非全体并列的集合开始，保留当时的领先集合；只有整个集合被外部答案严格超过才替换为新的领先集合，记录前后明确占优的时间界限。该保守定义可能不计最初并列成员内部后来发生的替换，主要锚点指标另作直接检查。
- 不确定状态不是错误或缺失；各类结果分别保留。

## 检查与交付

检查全部清单、config、标签/输入顺序、history尺寸、有限性、history末步与pred完全一致，并从history复算每步准确率、MSE、平均/最小间隔，与原metrics.jsonl核对。保存使用文件的SHA256，并在最后复核输入未变。

输出：逐序列/逐轨迹/逐锚点表、反转事件表、分组汇总、敏感性表、原始输入清单、可复跑脚本、独立核查脚本、中文报告、静态PNG/SVG图。图中案例按透明规则选取，全部案例保留在数据表，不能用插图的挑选代替总体结果。

若出现明确反例，足以否定该观测范围内“所有方向一步后都已锁定”的全称说法。若少有反转，也只能支持早期排序稳定，不能证明因果锁定，更不能单独解释二次响应近似。
